# Visual inspection and reference comparison

This is the record of **observations**, not a score automatically generated by a script.

## Capture the reference contract

Preserve the actual user reference(s), resolution/aspect ratio, typography/brand colors, copy, spacing constraints, expected behavior and all explicitly untouched regions. List visible versus hidden/unprovided states separately. For "replicate" identify objective anchors, e.g. header top, panel edges, logo bounding box, line height, shadow direction, contrast and button placement.

Keep reference and candidate at a comparable viewport/device scale before attempting direct comparison. Do not use an invented substitute when the actual reference is available.

## Each meaningful pass

```text
PASS N / REVISION:
  Actual rendering route: engine/tool + URL/path/revision + viewport/state
  Inspected: image opened? yes/no; frame timestamps, if motion
  Against: original reference / explicit contract (identify it)
  Observed deviation: concrete element, direction, approximate size or state
  Severity: critical / major / minor; requirement ID
  Decision: fix, preserve best, or explicit blocked status
  Changed candidate: revision + what changed
  Recheck: actual re-render opened + regressions checked
```

A capture must be **viewed**, not merely saved. If inspecting images is impossible, write `CAPTURED_NOT_VIEWED` and do not pass visual fidelity.

### What to inspect visually

- **Geometry:** alignment, margins, proportions, responsive hierarchy, safe areas, viewport scroll, off-canvas and ancestor clipping.
- **Typography/content:** weight, line breaks, fallback fonts, truncation, overlays, legibility and actual visible text.
- **Color/material:** gradient interpolation versus hard slices, translucency, reflection direction, plausible glass/specular geometry, glow falloff and aliasing.
- **Compositing:** overlaps, masks, shadows, layer order, contrast, antialiasing, unintended flashing/flicker.
- **Interaction/motion:** do not infer from a still; link to temporal and live-state checks in [motion-interaction](./motion-interaction.md).

A comparison image, sampled pixel delta or bounding-box measurement can provide useful evidence. It does **not** establish perceptual equivalence by itself: browser fonts, color profiles, viewport mismatch and moving content can produce differences. Conversely, a numeric zero-diff in a frozen frame can conceal wrong animation timing.

### Revision discipline

Use baseline → CODE/CHECK → FIX/CHECK → POLISH/CHECK; preserve best-known candidate before risky changes. Do not count changed CSS or new prompts as an inspection pass until their actual output is opened and judged. Aim for three meaningful passes for substantial visual creation unless evidenced otherwise. A bad third pass must not be the final "PASS."

## Truthful status matrix

| Status | Meaning |
| --- | --- |
| PASS | All applicable **critical** visual, temporal and interaction gates actually observed and passed, no unresolved major/critical defects |
| NEEDS_WORK | Real defect remains and can be repaired within authorized scope |
| PAUSED_RECOVERABLE | Incomplete due to turn/tool budget; last best candidate and exact next operation preserved |
| BLOCKED_ENV | Needed visual/temporal/interaction proof cannot be done after safe tool recovery |
| BLOCKED_PERMISSION | Necessary access/change awaits explicit permission |

Mark individual untested items `NOT_EVALUATED`; if critical, do **not** emit overall PASS. Separate self-review from independent criticism; do not report an external approval if no independent reviewer actually ran.

### Minimal public-safe example (not claimed test results)

```text
Reference: supplied image, 390px viewport
Candidate: r2, actual browser capture r2-mobile.png
Inspection: image opened; controls and hierarchy visible
Finding: required bottom action clipped by ancestor
Fix: r3 container sizing, then re-render and real click test
Verdict: NEEDS_WORK until r3 screenshot and click are checked
```

This is an illustrative **protocol**, not a screenshot the skill claims to have seen.
